PROPhish — İstifadə Təlimatı

Bu təlimat platformanın bütün funksiyalarını ilk quraşdırmadan kampaniya nəticələrinə qədər addım-addım izah edir. Hər bölmədə müvafiq ekranın görüntüsü və nə etməli olduğunuz göstərilir. PROPhish icazəli (authorized) təhlükəsizlik maarifləndirmə simulyasiyaları üçündür — parollar heç vaxt saxlanılmır, yalnız davranış faktı (açdı / klik etdi / göndərdi / bildirdi) qeyd olunur.

1İlk quraşdırma

Platforma ilk dəfə açılanda sizi quraşdırma ekranına yönləndirir. Burada ilk administrator hesabını yaradırsınız. Bu hesab bütün idarəetmə hüquqlarına malikdir və sonradan başqa operatorlar əlavə edə bilər.

  1. E-poçt ünvanınızı daxil edin (giriş üçün istifadə olunacaq).
  2. Güclü bir parol təyin edin — parol yalnız bcrypt hash kimi saxlanılır, açıq mətn kimi heç vaxt.
  3. Hesabı yarat düyməsini basın — avtomatik daxil olursunuz.

2Giriş

Administrator hesabı yaradıldıqdan sonra platforma sizi giriş ekranı ilə qarşılayır. E-poçt və parolla daxil olursunuz. Sağ yuxarıda tema (açıq/tünd) və dil (AZ / EN / RU) seçimi var.

🔒Admin paneli internetə birbaşa açılmamalıdır — onu yalnız daxili şəbəkədə və ya VPN/SSH tunnel arxasında saxlayın.

3Nəzarət paneli

Daxil olduqda ilk gördüyünüz ekran. Yuxarıda dörd əsas göstərici var: aktiv kampaniyalar, test olunmuş işçilər, orta klik faizi (aşağı = daha yaxşı) və phishing bildirmə faizi (yüksək = daha yaxşı). Aşağıda son kampaniyalar siyahısı göstərilir.

Toplu silmə

Son kampaniyalar cədvəlində hər sətrin solunda və başlıqda checkbox var. Tək-tək və ya hamısını seç ilə seçib Seçilənləri sil düyməsi ilə silə bilərsiniz (təsdiqdən sonra). Silinən kampaniyanın bütün nəticələri də silinir.

Soldakı panel bütün bölmələrə keçid verir: İş sahəsi (Nəzarət paneli, Kampaniyalar), Qurğu (Müştərilər, Şablonlar, Səhifələr, Kitabxana, SMTP profilləri) və Admin (İstifadəçilər, Parametrlər, Audit jurnalı).

4Müştərilər və icazələr

Hər kampaniya bir müştəriyə bağlıdır (öz təşkilatınız və ya xidmət göstərdiyiniz şirkət). Müştəri yaratdıqdan sonra onun səhifəsində icazə (authorization / RoE) əlavə etməlisiniz — bu, hüquqi qapıdır: kampaniya yalnız qüvvədə olan icazə varsa işə salına bilər.

  1. Müştərilər bölməsində yeni müştəri yaradın (ad, əlaqə e-poçtu, qeydlər).
  2. Müştərinin səhifəsində icazə əlavə edin: əhatə dairəsi (məs. *.şirkət.az), icazə verən şəxs, sənəd nömrəsi və qüvvədə olma tarixləri.
  3. Həmçinin bu səhifədə həmin müştəri üçün qruplar yaradırsınız.
⚠️İcazə olmadan və ya icazənin müddəti bitmişsə kampaniya işə salınmır — bu, sistemin qəsdən qoyulmuş qoruyucusudur.

5Qruplar və hədəflər

Qrup — birlikdə test ediləcək işçilərin siyahısıdır (məs. "Maliyyə Departamenti"). Qrupun səhifəsində hədəfləri tək-tək və ya CSV ilə toplu əlavə edirsiniz.

  1. Qrupu açın və hədəf əlavə edin: e-poçt, ad, soyad, vəzifə.
  2. Çoxlu hədəf üçün CSV faylı yükləyin.

6E-poçt şablonları

Hədəflərə göndəriləcək fişinq e-poçtunun məzmunu. Şablonda mövzu və HTML gövdə olur. Linkləri izləmək üçün {{"{{.TrackingURL}}"}} dəyişənindən istifadə edin — sistem onu hər hədəf üçün unikal izləmə linki ilə əvəz edir.

7Açılış səhifələri

İşçi linkə klikləyəndən sonra gördüyü səhifə (məs. saxta giriş səhifəsi). Üç yolla yarada bilərsiniz:

  1. URL-dən klonla — mövcud bir səhifəni çəkib açılış səhifəsinə çevirir; formalar avtomatik izlənməyə yönəldilir.
  2. Əl ilə — HTML gövdəni özünüz yazırsınız. Forma action="{{"{{.SubmitURL}}"}}" və method="post" olmalıdır.
  3. Vizual redaktor və ya Kitabxana (aşağıda).
🔐Təhlükəsizlik: daxil edilən parollar heç vaxt oxunmur və saxlanılmır — yalnız formanın göndərildiyi faktı qeyd olunur.

8Vizual redaktor

HTML bilmədən açılış səhifəsini sürükle-burax üsulu ilə yaratmaq üçün. Hazır bloklar, mətn, şəkil, forma elementləri əlavə edib dizaynı birbaşa görərək qurursunuz.

9Kitabxana

Hazır brend şablonları — Microsoft 365, Google, OneDrive, OWA, IT parol portalı və s. Sıfırdan yazmaq istəmirsinizsə, kitabxanadan hazır bir dəsti (e-poçt + açılış səhifəsi) seçib bir kliklə istifadəyə alırsınız.

10SMTP profilləri

E-poçtların hansı poçt serveri ilə göndəriləcəyini təyin edir: SMTP host, port, istifadəçi, "From" ünvanı. SMTP parolu şifrələnmiş saxlanılır (açıq mətn kimi yox).

✉️Test üçün daxili MailHog serverindən istifadə edə bilərsiniz (host mailhog, port 1025).

11Kampaniya yaratmaq

Bütün komponentləri birləşdirən addım. Kampaniya forması: ad, müştəri, icazə, qrup(lar), e-poçt şablonu, açılış səhifəsi və SMTP profili seçirsiniz. Ən vacib hissə — Listener (hədəflərin linkə haradan çatacağı) seçimidir.

Listener rejimləri

Hazırki host daxili / LAN

Linklər birbaşa bu serverin ünvanına işarə edir. Yalnız hədəflər həmin ünvana çata bildikdə (korporativ şəbəkə daxilində) işləyir. Public IP yoxdursa xaricdən açılmaz.

Cloudflare gateway tövsiyə / hər yerdən

Hər kampaniya üçün avtomatik https://…trycloudflare.com tuneli açılır. Hədəf linki ev, telefon, istənilən yerdən aça bilir və bağlantı HTTPS-dir. Yalnız serverdən çıxış (outbound) internet lazımdır.

Xüsusi URL öz domeniniz

Öz domeniniz və ya reverse proxy-niz varsa, tam URL-i əl ilə daxil edirsiniz (məs. https://secure.domeniniz.az).

⏱️Cloudflare gateway seçsəniz, tunel URL-i hazır olana qədər (~5-10 san) sistem göndərişi gözləyir — tez göndərsəniz belə linklər düzgün olur. Kampaniya göndərildikdən sonra serveri restart etməyin, əks halda tunel URL-i dəyişər.

12Nəticələr və hesabat

Kampaniya işə salındıqdan sonra detal səhifəsində real nəticələri izləyirsiniz: neçə nəfərə göndərildi, neçəsi açdı, klik etdi, məlumat verdi və phishing kimi bildirdi. Sağda ümumi risk balı (Aşağı / Orta / Yüksək) göstərilir.

  • Yenilə — nəticələri yeniləyir (tamamlanmış kampaniyalar avtomatik yenilənmir).
  • PDF hesabat — rəhbərliyə təqdim üçün hesabat.
  • CSV export — hədəf-səviyyəli nəticələr.
📊"Açıldı" piksel-əsaslıdır — bəzi poçt sistemləri şəkilləri bloklayır (açılma az görünə bilər) və ya linkləri avtomatik yoxlayır (açılma/klik şişə bilər).

13İstifadəçilər

Admin bölməsində əlavə operatorlar yarada, rolları (admin / operator) təyin edə və hesabları aktiv/deaktiv edə bilərsiniz.

14Parametrlər (IMAP)

Phishing-bildirmə qutusunu (işçilərin şübhəli e-poçtu yönləndirdiyi IMAP qutusu) konfiqurasiya edirsiniz. Sistem bu qutunu yoxlayıb hədəfləri avtomatik "bildirdi" kimi işarələyir — bu, müsbət göstəricidir.
